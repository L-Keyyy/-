# Web AI 页面修改器

这是一个独立的 Chrome / Edge 浏览器扩展，可以覆盖在普通 HTML、React、Next.js、Vue 和带后端的 Web 页面上。

它用于记录“页面应该怎么改”，不会把运行时 DOM 预览误当成最终代码。操作完成后，可以复制 AI 指令或导出结构化 JSON 修改单，再交给 AI 更新真实项目源码。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`tools/web-ai-editor-extension`。
5. 将“Web AI 页面修改器”固定在浏览器工具栏。

打开本地 HTML 文件时，还需要在扩展详情中打开“允许访问文件网址”。

## 使用流程

1. 打开需要调整的 Web 页面。
2. 点击扩展图标，或使用 `Command/Ctrl + Shift + E`。
3. 鼠标经过模块时会出现蓝色虚线，点击后选中。
   - 默认会自动选择最近的卡片、区块、表格或语义模块。
   - 按住 `Alt / Option` 点击，可以精确选择标题、按钮、单元格等内部元素。
4. 使用顶部工具栏完成操作：
   - 删除模块
   - 修改文字
   - 上移或下移
   - 复制模块
   - 在上方或下方新增模块占位
   - 调整宽度和最小高度
   - 添加给 AI 的文字说明
5. 使用撤回、重做或“清空记录”恢复页面。
6. 点击“复制AI指令”直接粘贴到 Codex；或点击“导出修改单”保存 JSON。

## 操作模式

- **选择模式**：点击页面内容只会选中模块，不会触发原网页交互。
- **页面操作模式**：点击“选择”按钮暂停框选，可以正常操作原网页。
- **Esc**：取消当前选择。
- **Command/Ctrl + Z**：撤回。
- **Command/Ctrl + Shift + Z**：重做。

## 导出的修改单包含什么

- 页面地址和页面标题
- 模块名称、稳定选择器和DOM标签
- 模块文字、HTML片段和页面位置
- 上下文模块
- 删除、移动、新增、文字、尺寸和批注要求
- 给 AI 的统一执行要求

AI获得项目源码和修改单后，可以把预览操作转换为真实的React组件、CSS、接口或后端字段修改。

## 适用范围

标准DOM页面覆盖度最高，包括企业后台、BI看板、表格、卡片、筛选器和详情弹窗。Canvas、WebGL、跨域iframe以及高度虚拟化页面会以外层容器为主要选择对象。

所有页面修改记录都保存在本机扩展存储中，导出动作也在本地完成。
